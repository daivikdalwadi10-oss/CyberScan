# Frontend (React + Vite)

## Overview
- Modern React (Vite) app
- Glass material UI, 12-column grid
- Centralized API client, error/retry logic
- Design tokens, theme provider, dark/light mode
- Role-based dashboards, widgets, charts
- Real-time metrics (WebSocket + polling)

## Scripts
- `npm install` — install dependencies
- `npm run dev` — start dev server
- `npm run build` — build for production

## Structure
- `src/app/` — Providers, entry
- `src/components/` — UI components
- `src/pages/` — Pages, dashboards
- `src/services/` — API, WebSocket
- `src/theme/` — Design tokens, theme

## Environment
- Copy `.env.example` to `.env` and set API URLs
